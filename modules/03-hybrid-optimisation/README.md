# Module 3 — Hybrid Estate Optimization

**Pillar:** Place it right · **Framework:** Infrastructure Placement Framework v1.0.0

---

## The question

You already run a hybrid infrastructure. Are the right workloads in the right environments today — and is the estate being governed and optimized on an ongoing basis?

---

## Context

Most organizations that have been operating hybrid infrastructure for several years have accumulated placement decisions that made sense individually but have never been reviewed as a portfolio. The result: cloud sprawl, idle resources, over-provisioned instances, ungoverned data, and infrastructure that costs significantly more than it should.

29% of SaaS licenses in the average organization are unused or underutilized (Flexera 2025). Cloud waste — idle VMs, orphaned storage, oversized instances — averages 28% of total cloud spend in organizations without active FinOps programs (CNCF 2024). Addressing these gaps without a structured governance baseline typically produces one-time cost savings that revert within 12 months.
