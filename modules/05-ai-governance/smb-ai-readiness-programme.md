# Module 5 — SMB AI Readiness Program

**90-Day Structured AI Adoption Program**

**Infrastructure Placement Framework · 4th and Bailey · v1.0.0**

---

## Who this is for

Small and mid-size businesses that want to adopt AI tools productively but don't know where to start. This program answers three questions SMBs actually have:

1. **What is safe to use?** — which tools are appropriate for your data and your sector
2. **Where do we start?** — which use cases deliver value fastest
3. **How do we know if it's working?** — metrics and governance that prove ROI

Structured on NIST AI RMF 1.0.

---

## Program overview

| Phase | Weeks | Focus |
|---|---|---|
| Phase 1 — Discover | 1–3 | Shadow AI audit, use case inventory, tool evaluation |
| Phase 2 — Govern | 4–6 | Policy, approved tool list, data classification |
| Phase 3 — Pilot | 7–10 | Controlled rollout of 1–2 use cases with governance |
| Phase 4 — Measure | 11–12 | Evaluate results, refine, plan next phase |

---

## Phase 1 — Discover (Weeks 1–3)

**Objective:** Understand what AI is already in use and where AI can genuinely help.

### Week 1 — Shadow AI discovery
- [ ] Complete shadow AI audit checklist (`shadow-ai-audit-checklist.md`)
- [ ] Run DNS/proxy log review for AI tool domains
- [ ] Send employee survey about current AI tool usage

### Week 2 — Use case inventory
Identify and prioritize AI use cases for your organization:

| Use case | Business function | Potential value | Data sensitivity | Priority |
|---|---|---|---|---|
| Email drafting and summarisation | All departments | High | Low | High |
| Meeting transcription and action items | All departments | High | Medium | High |
| Document summarisation | Legal / HR / Finance | High | High — needs enterprise tool | Medium |
| Customer support drafts | Customer service | High | Medium | High |
| Code assistance | IT / Development | High | High — no IP to be shared | Medium |
| Marketing copy | Marketing | Medium | Low | Medium |
| Data analysis and reporting | Finance / Operations | High | High — needs enterprise tool | Low (Phase 2) |

### Week 3 — Tool evaluation
- [ ] Complete AI vendor evaluation rubric for top 2–3 candidate tools
- [ ] Confirm enterprise data terms (DPA) for selected tools
- [ ] Present tool shortlist and recommendation to leadership

**Phase 1 output:** Shadow AI risk register + approved use case list + tool recommendation

---

## Phase 2 — Govern (Weeks 4–6)

**Objective:** Establish the governance foundation before deployment.

### Week 4 — Policy
- [ ] Customise and adopt AI acceptable use policy (`acceptable-use-policy-template.md`)
- [ ] Define data classification tiers for AI tool use
- [ ] Publish approved AI tool list

### Week 5 — Communication
- [ ] Communicate AI acceptable use policy to all staff
- [ ] Deliver 30-minute AI awareness session (what's approved, what's not, why it matters)
- [ ] Define escalation path for AI-related questions and incidents

### Week 6 — Technical controls
- [ ] Configure proxy/firewall to block or monitor non-approved AI tool domains
- [ ] Enable organizational controls in approved tools (data residency, opt-out of training)
- [ ] Set up usage logging for approved AI tools

**Phase 2 output:** Adopted acceptable use policy + technical controls in place + staff awareness delivered

---

## Phase 3 — Pilot (Weeks 7–10)

**Objective:** Controlled rollout of the top 1–2 approved use cases.

### Week 7 — Pilot group selection
- [ ] Select pilot group (10–20 employees across relevant function)
- [ ] Confirm pilot group understands the policy and approved use cases
- [ ] Define success metrics for each use case (see Phase 4)

### Weeks 8–10 — Pilot operation
- [ ] Monitor tool usage and data handling compliance
- [ ] Weekly check-in with pilot group: what's working, what's not
- [ ] Document incidents, near-misses, and policy questions that arise

**Phase 3 output:** Pilot group operational + usage data collected + incident log maintained

---

## Phase 4 — Measure (Weeks 11–12)

**Objective:** Evaluate results and plan the next phase.

### Success metrics

| Use case | Metric | Baseline | Target | Result |
|---|---|---|---|---|
| Email drafting | Time saved per email | | 5–10 min | |
| Meeting summaries | Time to produce action items | | 80% reduction | |
| Document summarisation | Review time per document | | | |

### Week 11 — Data collection
- [ ] Collect time-saving estimates from pilot group
- [ ] Review incident log — any policy violations or data exposure events?
- [ ] Review AI tool vendor's usage reports

### Week 12 — Review and next phase planning
- [ ] Present results to leadership: ROI evidence, incident summary
- [ ] Identify use cases ready for broader rollout
- [ ] Identify use cases for Phase 2 that require additional governance
- [ ] Complete NIST AI RMF assessment to establish formal maturity score (`nist-ai-rmf-assessment.md`)
- [ ] Plan Phase 2 program (next 90 days)

**Phase 4 output:** ROI report + incident summary + Phase 2 program plan + NIST RMF baseline score

---

## What success looks like at 90 days

- Shadow AI is understood and controlled — not necessarily eliminated, but governed
- 1–2 AI use cases are delivering measurable value with governance in place
- All employees know what is and is not permitted
- Governance ownership is assigned
- A roadmap exists for the next 90 days of AI adoption

This is not a technology transformation. It is a governance foundation that makes technology adoption safe and sustainable.
