## NIST AI 600-1 Generative AI Risk Categories

The following 12 risk categories from NIST AI 600-1 are addressed by Module 5:

| Risk category | Addressed by |
|---|---|
| CBRN Information (dangerous content generation) | Acceptable use policy — prohibited use cases |
| Confabulation (hallucination) | AUP — accuracy verification requirement |
| Data Privacy | Data classification policy + vendor evaluation rubric |
| Human-AI Configuration (over-reliance) | AUP — human review requirement |
| Information Integrity | AUP — verification and attribution |
| Information Security | Vendor evaluation rubric + shadow AI audit |
| Intellectual Property | AUP — IP protection clauses |
| Obscene, Degrading Content | AUP — acceptable use definitions |
| Toxic Language (bias, discrimination) | AUP — prohibited outputs |
| Value Chain and Component Integration | Vendor evaluation rubric |
| Data Privacy (training data exposure) | Vendor evaluation — training data opt-out |
| Prompt Injection | Addressed in vendor security section |
