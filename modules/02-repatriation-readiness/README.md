# Module 2 — Cloud Repatriation Readiness

**Pillar:** Place it right · **Framework:** Infrastructure Placement Framework v1.0.0

---

## The question

If you are considering moving workloads back from public cloud, are you organizationally, technically, and financially ready to do so successfully?

---

## Context

86% of CIOs planned to repatriate at least some public cloud workloads in 2025 (Barclays CIO Survey Q4 2024). 21% of workloads originally migrated to public cloud have already been repatriated (Flexera 2025). But only approximately 8% of organizations are doing a full cloud exit — the vast majority are recalibrating toward hybrid, not abandoning cloud entirely.

The key finding: the organizations that attempted repatriation without a readiness assessment frequently encountered the same failure modes — insufficient on-premises operational capability, underestimated capital expenditure, and hyperscaler dependency complexity that was not visible until migration began.

---

## What this module covers

| Topic | What it assesses |
|---|---|
| 3-year TCO comparison | Full cost model: cloud vs. private cloud vs. on-premises per candidate workload |
| VMware/Broadcom licensing exposure | Urgency and financial impact of Broadcom's 2024 perpetual license elimination |
| Team skills gap | Whether the organization can operate on-premises infrastructure competently post-repatriation |
| Hyperscaler dependency mapping | Which workloads have deep API or service dependencies that complicate migration |
| Repatriation sequencing | Which workloads to move first, which to move last, and which should stay in cloud permanently |

## Output

Completing this module produces:

1. A repatriation readiness score across five dimensions
2. A prioritized workload migration sequence (repatriate first → repatriate later → remain in cloud)
3. A risk register for the repatriation transition
4. A skills gap analysis with recommended remediation
5. A VMware/Broadcom exposure assessment with recommended action

---

## Readiness thresholds

A readiness score below 60% in any dimension is a flagged risk that must be addressed before repatriation sequencing begins. Organizations with multiple sub-60% dimensions should treat repatriation planning as a multi-phase program, not a single migration event.
